# Parts Bench: start here

**Continuing this tool? Read [the detailed handover](HANDOVER.md).** For pictures and operation, use the [manual](USER-MANUAL.md) and [offline demo](../demo.html).

Versioned model library, physical filament batches, parameter recommendations, diagnosis, print verification and immutable job evidence. Newer NAS inbox/spool work has advanced beyond this package checkpoint.

**Start with:** Create traceable material and part records. Start in Library. Add a spool or import a supported filament profile; record the batch instead of treating all spools of a product as interchangeable.

**Source:** this is a private source checkpoint, not a live-system mirror. Check [the source manifest](../SOURCE-MANIFEST.json) and current working files before merging.

**Keep your work safe:** The library owns its model-folder layout, metadata and database. Back up the complete root including _bench, not only the visible STL files. Browser drafts and saved shared records are different. Print-job snapshots/attempt history need their own preserved storage.

**Next maintainer action:** Reconcile the newer working NAS changes before the next source refresh. Test safe import/rename, revisions, exact loaded spool and job guards on fixtures. Never start a real print as a routine test. Historical September no-login/no-dependencies claims describe the old local build, not the current authenticated NAS system.
