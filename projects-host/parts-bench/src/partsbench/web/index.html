Fault diagnosis

Written for a maintained machine. Kinematic and frame causes are ranked last on purpose; consumable wear, moisture and parameter drift are ranked first because that is what actually fails on a serviced fleet.

Hotends & nozzles

Each entry carries an effective melt-zone volume, which is the single parameter the flow model runs on. Add your Revo and aftermarket combinations here; measure one, and the model predicts the rest.

Change history

Every save is diffed against what was there before, so the record shows which fields moved and what they moved from. Useful when a spool that printed well last month stops behaving.
